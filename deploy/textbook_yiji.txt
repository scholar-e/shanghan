辨伤寒宜忌脉症篇第十五 / 忌发汗第一
涪陵古本 宜忌 YJ.1: 太阳病，发热恶寒，寒多热少，脉微弱，则无阳也，忌复发其汗。
涪陵古本 宜忌 YJ.2: 咽喉干燥者，忌发其汗。
（宋本 83）咽喉干燥者，不可发汗。
涪陵古本 宜忌 YJ.3: 太阳病发其汗，因致痉。
涪陵古本 宜忌 YJ.4: 少阴病，脉细沉数，病在里，忌发其汗。
涪陵古本 宜忌 YJ.5: 少阴病，脉微，忌发其汗，无阳故也。
涪陵古本 宜忌 YJ.6: 脉浮而紧，法当身体疼痛，当以汗解。假令尺中脉迟者，忌发其汗。何以知然？此为荣气不足，血气微少故也。
涪陵古本 宜忌 YJ.7: 咽中闭塞，忌发其汗，发其汗即吐血，气微绝，逆冷。
涪陵古本 宜忌 YJ.8: 厥逆忌发其汗，发其汗，即声乱、咽嘶、舌痿。
涪陵古本 宜忌 YJ.9: 亡血家，忌攻其表，汗出则寒栗而振。
（宋本 87）亡血家不可发汗，发汗则寒栗而振。
涪陵古本 宜忌 YJ.10: 衄家，忌攻其表，汗出，必额上陷，脉促急。
（宋本 86）衄家不可发汗，汗出必额上陷，脉急紧，直视不能眴（一作瞬）不得眠。
涪陵古本 宜忌 YJ.11: 汗家，重发其汗，必恍惚心乱，小便已，阴痛（涪古本作疼）。
涪陵古本 宜忌 YJ.12: 淋家，忌发其汗，发其汗必便血。
（宋本 84）淋家不可发汗，发汗必便血。
涪陵古本 宜忌 YJ.13: 疮家，忌发汗（涪古本无“忌发汗”），虽身疼痛，忌攻其表，汗出则痉。
（宋本 85）疮家虽身疼痛，不可发汗，汗出则痉。
涪陵古本 宜忌 YJ.14: 冬时忌发其汗，发其汗必吐利，口中烂，生疮。
涪陵古本 宜忌 YJ.15: 咳而小便利，若失小便，忌攻其表，汗出则厥逆冷。

辨伤寒宜忌脉症篇第十五 / 宜发汗第二
涪陵古本 宜忌 YJ.16: 大法，春夏宜发汗。
涪陵古本 宜忌 YJ.17: 太阳病，脉浮而数者，宜发其汗。
涪陵古本 宜忌 YJ.18: 太阳中风，阳浮而阴濡弱，浮者热自发，濡弱者，汗自出。啬啬恶寒，淅淅恶风，翕翕发热，鼻鸣干呕，桂枝汤主之。
涪陵古本 宜忌 YJ.19: 太阳头痛发热， 身体疼， 腰痛， 骨节疼痛， 恶风， 无汗而喘， 麻黄汤主之。
涪陵古本 宜忌 YJ.20: 太阳中风，脉浮紧，发热恶寒，身体痛，不汗出而烦躁，大青龙汤主之。
涪陵古本 宜忌 YJ.21: 阳明病，脉虚浮者，宜发其汗。
涪陵古本 宜忌 YJ.22: 阳明病，其脉迟，汗出多而微恶寒者，表为未解，宜发其汗。
涪陵古本 宜忌 YJ.23: 太阴病，脉浮，宜发其汗。
涪陵古本 宜忌 YJ.24: 少阴病，得之二三日，麻黄附子甘草汤，微发汗。
涪陵古本 宜忌 YJ.25: 凡发汗，欲令手足皆周，漐漐一时间益佳，不欲流漓。若病不解，当重发汗。然汗多亡阳，阳虚不得重发汗也。
涪陵古本 宜忌 YJ.26: 凡服汤药，发汗中病即止，不必尽剂也。
涪陵古本 宜忌 YJ.27: 凡云：宜发汗而无汤者，丸散亦可用，然不如荡药也。
涪陵古本 宜忌 YJ.28: 凡脉浮者，病在外，宜发其汗。

辨伤寒宜忌脉症篇第十五 / 忌吐第三
涪陵古本 宜忌 YJ.29: 太阳病，恶寒而发热，今自汗出，反不恶寒而发热，关上脉细而数，此吐之过也。
涪陵古本 宜忌 YJ.30: 少阴病，其人饮食入则吐，心中嗢嗢欲吐，复不能吐，始得之，手足寒，脉弦迟。若膈上有寒饮，干呕，忌吐，当温之。

辨伤寒宜忌脉症篇第十五 / 宜吐第四
涪陵古本 宜忌 YJ.32: 大法，春宜吐。
涪陵古本 宜忌 YJ.33: 凡服吐汤，中病便止，不必尽剂也。
涪陵古本 宜忌 YJ.34: 病如桂枝证，其头项不强痛，寸口脉浮，胸中痞坚，上冲咽喉不得息，此为有寒，宜吐之。
涪陵古本 宜忌 YJ.35: 病胸上诸实，胸中郁郁而痛，不能食，欲使人按之，而反有涎唾下利，日十余行，其脉反迟，寸口脉微滑，此宜吐之，利即止。
涪陵古本 宜忌 YJ.36: 少阴病，其人饮食入则吐，心中嗢嗢欲吐，复不能吐，宜吐之。
涪陵古本 宜忌 YJ.37: 病者手足逆冷，脉乍紧，邪结在胸中，心下满而烦，饥不能食，病在胸中，宜吐之。
涪陵古本 宜忌 YJ.38: 宿食在上管，宜吐之。

辨伤寒宜忌脉症篇第十五 / 忌下第五
涪陵古本 宜忌 YJ.39: 太阳证不罢，忌下，下之为逆。
涪陵古本 宜忌 YJ.40: 太阳与阳明合病，喘而胸满者，忌下。
涪陵古本 宜忌 YJ.41: 太阳与少阳合病，心下痞坚，颈项强而头眩，忌下。
涪陵古本 宜忌 YJ.42: 咽中闭塞，忌下，下之则上轻下重，水浆不下。
涪陵古本 宜忌 YJ.43: 诸外实忌下，下之皆发微热，亡脉则厥。
涪陵古本 宜忌 YJ.44: 诸虚忌下，下之则渴。饮水易愈，恶水者剧。
涪陵古本 宜忌 YJ.45: 脉数者，忌下，下之必烦，利不止。
涪陵古本 宜忌 YJ.46: 尺中弱涩者，复忌下。
涪陵古本 宜忌 YJ.47: 脉浮大，医反下之，此为大逆。
涪陵古本 宜忌 YJ.48: 结胸证，其脉浮大，忌下，下之即死。
涪陵古本 宜忌 YJ.49: 凡四逆证（涪古本作病）厥者，忌下，虚家亦然。
涪陵古本 宜忌 YJ.50: 病欲吐者，忌下。
涪陵古本 宜忌 YJ.51: 病有外证未解，忌下，下之为逆。
涪陵古本 宜忌 YJ.52: 少阴病，食入即吐，心中嗢嗢欲吐，复不能吐。始得之，手足寒，脉弦迟。此胸中实，忌下。
涪陵古本 宜忌 YJ.53: 伤寒五六日，不结胸，腹濡，脉虚复厥者，忌下，下之亡血则死。

辨伤寒宜忌脉症篇第十五 / 宜下第六
涪陵古本 宜忌 YJ.54: 大法，秋宜下。
涪陵古本 宜忌 YJ.55: 阳明病，发热，汗多者，急下之。
涪陵古本 宜忌 YJ.56: 阳明与少阳合病，利而脉不负者为顺。脉数而滑者，有宿食，宜下之。
涪陵古本 宜忌 YJ.57: 少阴病，得之二三日，口燥咽干者，急下之。
涪陵古本 宜忌 YJ.58: 少阴病，五六日，腹满不大便者，急下之。
涪陵古本 宜忌 YJ.59: 少阴病，下利清水，色青者，心下必痛。口干者，急下之。
涪陵古本 宜忌 YJ.60: 下利，三部脉皆浮，按其心下坚者，宜下之。
涪陵古本 宜忌 YJ.61: 下利，脉迟而滑者，实也。利未欲止，宜下之。
涪陵古本 宜忌 YJ.62: 凡宜下，以汤胜丸散。
涪陵古本 宜忌 YJ.63: 凡服汤下，中病则止，不必尽三服。
涪陵古本 宜忌 YJ.64: 问曰：病人有宿食，何以别之？答曰：寸口脉浮大，按之反涩，尺中亦微而涩，故知有宿食，宜下之。
涪陵古本 宜忌 YJ.65: 凡病腹中满痛者，为实，宜下之。
涪陵古本 宜忌 YJ.66: 腹满不减，减不足言，宜下之。
涪陵古本 宜忌 YJ.67: 伤寒六七日，目中不了了，睛不和，无表里证，大便难，身微热者，此为实，宜下之。
涪陵古本 宜忌 YJ.68: 脉双弦而迟，心下坚，脉大而紧者，阳中有阴，宜下之。
涪陵古本 宜忌 YJ.69: 伤寒有热，而少腹满，应小便不利，今反利，此为血，宜之下。
涪陵古本 宜忌 YJ.70: 病者烦热，汗出即解。复如疟，日晡所发者，属阳明，脉实者，当下之。
涪陵古本 宜忌 YJ.71: 下利差，至其时复发，此为病不尽，宜复下之。 其他宜忌

辨伤寒宜忌脉症篇第十五 / 宜温第七
涪陵古本 宜忌 YJ.72: 大法，冬宜服温热药。
涪陵古本 宜忌 YJ.73: 师曰：病发热头痛，脉反沉，若不差，身体更疼痛。当救其里，宜温药四逆汤。
涪陵古本 宜忌 YJ.74: 下利，腹胀满，身体疼痛，先温其里，宜四逆汤。
涪陵古本 宜忌 YJ.75: 下利，脉迟紧，为痛未欲止，宜温之。
涪陵古本 宜忌 YJ.76: 下利，脉浮大者，此为虚，以强下之故也，宜温之，与水必哕。
涪陵古本 宜忌 YJ.77: 少阴病下利，脉微涩，呕者，宜温之。
涪陵古本 宜忌 YJ.78: 自利不渴者，属太阴，其藏有寒故也，宜温之。
涪陵古本 宜忌 YJ.79: 少阴病，其人饮食入则吐，心中嗢嗢欲吐，复不能吐。始得之，手足寒，脉弦迟。若膈上有寒饮，干呕，宜温之。
涪陵古本 宜忌 YJ.80: 少阴病，脉沉者，宜急温之。
涪陵古本 宜忌 YJ.81: 下利，欲食者，宜就温之。

辨伤寒宜忌脉症篇第十五 / 忌火第八
涪陵古本 宜忌 YJ.82: 伤寒，加火针，必惊。
涪陵古本 宜忌 YJ.83: 伤寒脉浮，而医以火迫劫之，亡阳，必惊狂，卧起不安。
涪陵古本 宜忌 YJ.84: 伤寒，其脉不弦紧而弱，弱者必渴，被火，必谵语。
涪陵古本 宜忌 YJ.85: 太阳病，以火熏之不得汗，其人必躁，到经不解，必清血。
涪陵古本 宜忌 YJ.86: 阳明病被火，额上微汗出，而小便不利，必发黄。
涪陵古本 宜忌 YJ.87: 少阴病，咳而下利，谵语，是为被火气劫故也。小便必难，为强责少阴汗。

辨伤寒宜忌脉症篇第十五 / 宜火第九
涪陵古本 宜忌 YJ.88: 凡下利，谷道中痛，宜灸枳实，若熬盐等熨之。

辨伤寒宜忌脉症篇第十五 / 忌灸第十
涪陵古本 宜忌 YJ.89: 微数之脉，慎不可灸，因火为邪，则为烦逆。
涪陵古本 宜忌 YJ.90: 脉浮，当以汗解，而反灸之，邪无从去，因火而盛，病从腰以下必重而痹，此为火逆。
涪陵古本 宜忌 YJ.91: 脉浮热甚，而反灸之，此为实，实以虚治，因火而动，咽燥必唾血。

辨伤寒宜忌脉症篇第十五 / 宜灸第十一
涪陵古本 宜忌 YJ.92: 少阴病一二日，口中和，其背恶寒，宜灸之。
涪陵古本 宜忌 YJ.93: 少阴病，吐利，手足逆而脉不足，灸其少阴七壮。
涪陵古本 宜忌 YJ.94: 少阴病，下利，脉微涩者，即呕，汗者必数更衣，反少者，宜温其上，灸之（一云灸厥阴五十壮）。
涪陵古本 宜忌 YJ.95: 下利，手足厥，无脉，灸之，主厥，厥阴是也。灸不温反微喘者，死。
涪陵古本 宜忌 YJ.96: 伤寒六七日，其脉微，手足厥，烦躁，灸其厥阴，厥不还者，死。
涪陵古本 宜忌 YJ.97: 脉促，手足厥者，宜灸之。

辨伤寒宜忌脉症篇第十五 / 忌刺第十二
涪陵古本 宜忌 YJ.98: 大怒无刺，新内无刺，大劳无刺，大醉无刺，大饱无刺，大渴无刺，大惊无刺。无刺熇熇之热，无刺渌渌之汗，无刺浑浑之脉，无刺病与脉相逆者。
涪陵古本 宜忌 YJ.99: 上工刺未生，其次刺未盛，其次刺其衰。工逆此者，是谓伐形。

辨伤寒宜忌脉症篇第十五 / 宜刺第十三
涪陵古本 宜忌 YJ.100: 太阳病，头痛至七日，自当愈，其经竟，故也。若欲作再经者，宜刺足阳明，使经不传则愈。
涪陵古本 宜忌 YJ.101: 太阳病，初服桂枝汤，而反烦不解，宜先刺风池，风府，乃却与桂枝汤则愈。
涪陵古本 宜忌 YJ.102: 伤寒，腹满而谵语，寸口脉浮而紧者，此为肝乘脾，名曰纵。宜刺期门。
涪陵古本 宜忌 YJ.103: 伤寒发热，啬啬恶寒，其人大渴，欲饮酢浆者，其腹必满，而自汗出，小便利，其病欲解。此为肝乘肺，名曰横，宜刺期门。
涪陵古本 宜忌 YJ.104: 阳明病，下血而谵语，此为热入血室。但头汗出者，刺期门，随其实而泻之。
涪陵古本 宜忌 YJ.105: 太阳与少阳合病， 心下痞坚， 颈项强眩， 宜刺大椎、肺俞、肝俞， 勿下之。
涪陵古本 宜忌 YJ.106: 妇人伤寒，怀身，腹满不得小便，加从腰以下重，如有水气状，怀身七月，太阴当养不养，此心气实，宜刺泻劳宫及关元，小便利则愈。
涪陵古本 宜忌 YJ.107: 伤寒喉痹，刺手少阴穴，在腕当小指后动脉是也。针入三分补之。
涪陵古本 宜忌 YJ.108: 少阴病，下利便脓血者，宜刺。

辨伤寒宜忌脉症篇第十五 / 忌水第十四
涪陵古本 宜忌 YJ.109: 发汗后，饮水多者，必喘，以水灌之亦喘。
涪陵古本 宜忌 YJ.110: 下利，其脉浮大，此为虚，以强下之故也，设脉浮革，因尔肠鸣，当温之，与水必哕。
涪陵古本 宜忌 YJ.111: 太阳病，小便利者，为水多，心下必悸。

辨伤寒宜忌脉症篇第十五 / 宜水第十五
涪陵古本 宜忌 YJ.112: 太阳病，发汗后，若大汗出，胃中干，躁烦不得眠，其人欲饮水，当稍饮之，令胃气和则愈。
涪陵古本 宜忌 YJ.113: 厥阴渴欲饮水，与水饮之，则愈。
涪陵古本 宜忌 YJ.114: 呕吐，膈上者，必思煮饼，急思水者，与五苓散饮之，水亦得也。
